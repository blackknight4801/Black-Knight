Rules & Guidelines

As is elsewhere, I too have policies to be kept:

  • NSFW & 18+ content: I refuse to create bots for such activities, especially if the server is NOT set as 18+. I still might create some bots in such manner, provided that the server itself is set as 18+
  • Specified servers: I offer to create bots that can only normally function in specific servers, and some functions most probably won't work in other servers. If you desire a bot for multiple servers, do mention when ordering!
  • Leveling system: I refuse to create a leveling system for discord bots. If you do want something as such, I suggest using Arcane or another, widely known and used bot instead.

Packages

These can be mixed and matched. Atleast one of these is required!

Simple Bot

This package includes:

  • Timeout command: timeouts the given member for the specified duration.
  • Kick command: kicks the specified member for the given reason (if any).
  • Ban command: bans the specified member for the given reason and duration.

Cost: 1$/1€

Logging system

This package comes with a logging system. Commands will be made to remove, edit, and/or add channels to a specified logging theme (example: deleted messages).
The logging system will be harmonized to work with all other packages flawlessly and will also be able to log actions made by members or others bots.

Cost: 2$/2€

Warn system

A warn system that can be used to discipline members.
This package will normally come with the following commands:

  • /warn add: used to warn/add a warn to the specified member, for given reason and duration. Can optionally have severity.
  • /warn list: lists the warnings (with all data) of a member. 5 warns per "page". Requires a member as target.
  • /warn remove: removes the given warn by id. Requires the id of the warn.

Cost: 3$/3€
