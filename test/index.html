Disnake: The Start

This tutorial will show you how to create the most simple discord bot there is and run it.
First, let's create a discord bot:

  1. Visit the Discord Developer Portal and create an "application" (Log in when prompted).
  2. Once the bot is created, it should be "opened". On the left, choose the "Bot" tab (Discord may prompt you to turn the application into a bot - just continue with it)
  3. Now, turn on all options that have "Intent" in them and save the change.
  4. Press "Reset Token", do whatever discord prompts you to do then press "Copy Token" and save it for later.

Now that we have created our Bot and we have its token, let's start writing the code itself.

Create a python file (e.g bot.py) and open it, then paste in the following:

/ > bot.py
